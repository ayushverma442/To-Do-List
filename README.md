# ✅ To-Do List App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript to help users organize tasks and manage their daily activities.

## 🌐 Live Demo

🚀 **[View To-Do List App](https://to-do-list-eight-psi-98.vercel.app/)**

## 📌 Overview

The To-Do List App is a frontend web development project that demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive application.

The project focuses on DOM manipulation, event handling, user input, and dynamic updates to build a functional task management interface.

## ✨ Features

- ➕ Add new tasks
- 📅 Assign due dates to tasks
- 📝 Enter tasks through an input field
- ⚡ Update the task list dynamically
- 🎨 Simple and clean user interface
- 🖥️ Runs directly in a web browser

## 🛠️ Technologies Used

- **HTML5** — Structures the application
- **CSS3** — Styles the interface and layout
- **JavaScript** — Implements application logic and interactivity
- **Git** — Tracks changes to the source code
- **GitHub** — Hosts the project repository
- **Vercel** — Deploys the application
